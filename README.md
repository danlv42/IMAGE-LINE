# IMAGE-LINE — собственный lossy-кодек изображений

## LSC v2

Реализован собственный блочный кодек с потерями:
- RGB → YCbCr;
- субдискретизация цветности 4:2:0;
- блочное преобразование DCT 8×8;
- квантование коэффициентов;
- зигзагообразная перестановка коэффициентов;
- сжатие потока коэффициентов через zlib;
- подбор масштаба и качества под жёсткий лимит размера;
- декодирование в PNG или другой формат Pillow.

Кодек не вызывает JPEG/WebP/AVIF для кодирования. Таблицы квантования вдохновлены стандартными таблицами JPEG, но контейнер LSC2 и реализация кодирования/декодирования собственные.

## Установка

```bash
python -m venv .venv
```

Windows PowerShell:
```powershell
.venv\Scripts\Activate.ps1
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Зависимости:
```bash
pip install -r requirements.txt
```

## CLI

Сжать изображение в файл не более 200 КБ:
```bash
python codec.py encode photo.jpg photo.lsc --max-kb 200
```

Декодировать:
```bash
python codec.py decode photo.lsc restored.png
```

Если лимит слишком мал для проверенных вариантов, программа выдаст ошибку вместо записи файла, который превышает лимит.

## Текущие ограничения

- Подбор параметров перебирает сетку масштабов и quality, поэтому может быть медленным на больших изображениях.
- Выбор лучшего кандидата пока эвристический: сначала максимизируется число сохранённых пикселей, затем quality. Это не гарантирует оптимального перцептивного качества.
- Для турнирной версии нужно добавить тесты, сравнение по SSIM/LPIPS, адаптивное квантование по блокам, ускорение поиска и защиту API от параллельных запросов (сейчас API использует фиксированные временные имена).
- LSC v2 несовместим с файлами LSC v1.
