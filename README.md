# IMAGE-LINE — собственный lossy-кодек изображений

## LSC v3

IMAGE-LINE — экспериментальный собственный блочный кодек с потерями. Он не использует JPEG, WebP или AVIF как кодер.

Текущий pipeline:
- RGB → YCbCr;
- chroma subsampling 4:2:0;
- блочное преобразование DCT-II 8×8;
- адаптивное квантование по активности блоков: три умеренных уровня для Y, Cb и Cr;
- zigzag scan;
- zlib-сжатие массива коэффициентов;
- подбор масштаба и quality в рамках заданного ограничения;
- декодирование LSC в PNG или другой формат Pillow.

LSC3 — собственный контейнер и реализация кодирования/декодирования. Внутри файла сохраняются индексы адаптивных квантователей блоков. Таблицы квантования используют JPEG-подобные стартовые веса. Декодер также сохраняет чтение ранее созданных LSC2-файлов.

## CLI

Закодировать изображение в файл размером не более 200 KiB:
```bash
python codec.py encode photo.jpg photo.lsc --max-kb 200
```

Декодировать:
```bash
python codec.py decode photo.lsc restored.png
```

Если проверенные кандидаты не помещаются в лимит, кодер сообщает об этом и не записывает превышающий лимит результат.

## Веб-интерфейс и API

Запустить локальный сервер:
```bash
uvicorn api:app --reload
```

Откройте http://127.0.0.1:8000/ — там можно выбрать изображение, задать лимит, увидеть оригинал рядом с восстановленным изображением и получить ссылку на LSC-файл.

Swagger API: http://127.0.0.1:8000/docs

Основные маршруты:
- `GET /health` — проверка состояния;
- `POST /encode` — загрузка изображения и кодирование с `max_kb`;
- `POST /decode` — декодирование загруженного LSC;
- `GET /files/{token}/{filename}` — получение результата конкретной задачи.

API хранит файлы каждой задачи в отдельной директории и использует случайный идентификатор, чтобы одновременные запросы не перезаписывали общий `upload`, `encoded.lsc` или `restored.png`. Временные задачи сейчас не очищаются автоматически.

## Сравнение LSC2 и LSC3 при одинаковом лимите

Скрипт `benchmark.py` кодирует одни и те же тестовые изображения обеими реализациями при одинаковом максимальном размере, затем декодирует и считает PSNR, global SSIM и RGB MAE. Результат записывает в CSV.

1. Скачайте старую реализацию LSC2 из ветки `main` как отдельный файл `codec_lsc2.py`.
2. Запустите сравнение из рабочей копии ветки LSC3:

```bash
python benchmark.py ./test_images --baseline-codec ./codec_lsc2.py --max-kb 200 --csv results.csv
```

Для одного изображения можно передать путь вместо каталога. Используйте одинаковый набор изображений и бюджет для каждого эксперимента. Более высокий PSNR/SSIM и меньший MAE означают лучшее сходство с оригиналом в рамках этих метрик.

**Важно:** реализованный SSIM — global SSIM по RGB-каналам, а не локальный оконный SSIM и не полноценная перцептивная оценка. Это сравнительный диагностический показатель; визуальные артефакты и субъективное качество также нужно проверять. Если кодек не может подобрать файл в заданный лимит, запуск завершится ошибкой для этого изображения.

## Ограничения и дальнейшая работа

- DCT-преобразования теперь кэшируются на каждом масштабе и повторно используются при переборе quality. Это уменьшает повторную работу на стадии трансформации; фактический выигрыш зависит от изображения и машины.
- Поиск параметров всё ещё перебирает сетку масштабов и quality; большие изображения могут обрабатываться медленно.
- Адаптивность использует ранжирование AC-активности блоков и три фиксированных множителя (0.90×, 1.00×, 1.10×); это эвристика, не обученная perceptual-модель.
- Критерий выбора кандидата пока эвристический и не равен оптимизации перцептивного качества.
- Следующие технические задачи для турнирной версии: сделать поиск размера более эффективным, оценивать SSIM/MS-SSIM или LPIPS на тестовой выборке и подобрать/проверить параметры адаптивного квантования на корпусе изображений.
- Базовые регрессионные тесты запускаются командой `python -m unittest discover -s tests`.
- Не заявляется, что текущая версия превосходит JPEG/WebP/AVIF: это нужно подтвердить сравнительными тестами на одинаковом размере файла.
- Новые результаты записываются в LSC3; декодер поддерживает LSC2, но старый LSC2-декодер не читает файлы LSC3.
