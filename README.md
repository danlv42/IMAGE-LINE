# IMAGE-LINE — собственный lossy-кодек изображений

Первая версия собственного формата изображений `.lsc`.

## Возможности

- Кодирование изображения в собственный контейнер `.lsc`.
- Декодирование `.lsc` в PNG/JPEG и другие форматы Pillow.
- Перебор масштаба изображения и уровней цветового квантования с заданным жёстким лимитом размера.
- CLI и API на FastAPI.

## Установка

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Зависимости:
```bash
pip install -r requirements.txt
```

## Использование

Сжать изображение до 200 КБ:
```bash
python codec.py encode photo.jpg photo.lsc --max-kb 200
```

Восстановить изображение:
```bash
python codec.py decode photo.lsc restored.png
```

Если ни один проверенный вариант не помещается в лимит, кодер сообщает об ошибке и не сохраняет файл, превышающий ограничение.

## Запуск API

```bash
uvicorn api:app --reload
```

API docs: http://127.0.0.1:8000/docs

## Устройство формата

Файл содержит сигнатуру `LSC1`, длину JSON-заголовка, JSON-метаданные и RGB-пиксели, сжатые zlib. Потери обеспечиваются уменьшением разрешения и равномерным квантованием цветов.

## Важное ограничение

Это MVP для разработки и экспериментов, а не готовый турнирный кодек. Стратегия выбора сейчас приоритизирует разрешение, затем количество уровней цвета; это не гарантирует наилучшее визуальное качество. Следующие улучшения: адаптивное квантование блоков, преобразование цвета, DCT, оценка SSIM/перцептивных метрик, тесты и безопасная изоляция временных файлов в API.
